# AI Roleplay + Image Creator A JavaScript app for: - interactive roleplay chat - AI image generation - optional real AI integration with OpenRouter and Hugging Face - demo mode that works without API keys ## Run locally ```bash npm install npm start ``` Then open http://localhost:3000 ## API setup Copy `.env.example` to `.env` and add your keys: ```bash cp .env.example .env ``` Example: ```env OPENROUTER_API_KEY=your_key_here OPENROUTER_MODEL=anthropic/claude-3.5-sonnet HUGGINGFACE_API_KEY=your_key_here HUGGINGFACE_IMAGE_MODEL=black-forest-labs/FLUX.1-dev ``` If you want a Grok-like experience, use an OpenRouter model such as: - x-ai/grok-beta - anthropic/claude-3.5-sonnet - openai/gpt-4o-mini ## Features - roleplay with adjustable persona - instant AI image generation - polished single-page interface - demo fallback when no API keys are available ## Deploy This app is ready for free deployment on Render or Railway.
